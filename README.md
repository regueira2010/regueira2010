### Infraestructura · Desarrollo · Cloud

Hola bienvenido a este repositorio. Mi historia en la tecnología no empezó frente a un editor de código, sino desarmando ordenadores, configurando redes y asegurando que los equipos y servidores de empresas funcionaran sin fallar. 

Durante mucho tiempo, programar fue mi hobby: hacía proyectos que vivían guardados en mi disco local, impulsado por las ganas de entender cómo funcionaban las cosas por dentro. Con los años decidí tomarme esto en serio y dar el salto formal al desarrollo de software para llevar ideas desde cero hasta producción. 

Así nació este GitHub: mi espacio para construir proyectos propios y resolver desafíos reales, evitando el clásico "copiar y pegar tutoriales" para inflar un perfil. Mi ruta técnica fue sumando piezas con intención:
* **El inicio:** HTML, CSS, JavaScript y React para dominar el frontend interactivo.
* **La evolución Full Stack:** Node.js, Express y bases de datos relacionales para construir servicios completos.
* **La consolidación backend:** Java 21 y Spring Boot 3 con foco en arquitectura, buenas prácticas y TDD.
* **El ecosistema Cloud:** AWS (Certified Cloud Practitioner), Google Cloud (Fundamentos: Infraestructura Core), cerrando el círculo entre el código y la infraestructura donde vive.

Paralelamente, entiendo que la tecnología no vive aislada del negocio ni de los equipos:  se necesita **Gestión de Proyectos de Google** (Agile / Scrum), formación en negociación **ESADE**, y mantengo un entrenamiento constante en **inglés para la industria IT**.

Si estás por acá, siéntete libre de explorar mis repositorios, revisar el código o ver las arquitecturas en las que he estado trabajando.

### Proyectos en los que he estado trabajando

#### [AWS Cloud Catalog Ecosystem](https://github.com/regueira2010/AWS-API-JAVA)
> **Ecosistema Full Stack: Backend Java 21 / Spring Boot 3 + Cliente SPA React 19**
* **La idea:** Catálogo interactivo de más de 280 servicios de AWS, sinergias de certificación y capa gratuita, desarrollado bajo arquitectura desacoplada de alto rendimiento.
* **Backend ([AWS-API-JAVA](https://github.com/regueira2010/AWS-API-JAVA)):** Arquitectura Hexagonal, control de tráfico con Bucket4j (Rate-Limiting), caché L1 con Caffeine, validación condicional ETag (HTTP 304), Flyway migrations y Docker. Desplegado en Render con Swagger UI y OpenAPI spec.
* **Frontend ([aws-services-client](https://github.com/regueira2010/aws-services-client)):** React 19, Tailwind CSS v4, búsqueda debounced en tiempo real, persistencia en localStorage con revalidación y CI/CD con GitHub Actions.
* **Stack:** `Java 21` `Spring Boot 3` `React 19` `Tailwind CSS v4` `PostgreSQL 16` `Flyway` `Caffeine` `Docker` `Render` `OpenAPI`

#### [TaskPoints](https://github.com/regueira2010/taskpoints)
> **Tablero de priorización y gestión diaria basado en la Matriz de Eisenhower**
* **La idea:** Crear una herramienta de productividad visual que fuera 100% autónoma en el navegador, rápida y que no requiriera un servidor backend para operar.
* **Qué exploré aquí:** React 19 con Zustand para el estado, y la API nativa `BroadcastChannel` para sincronización en tiempo real entre múltiples pestañas abiertas. Empaquetado ligero en Docker con Nginx.
* **Stack:** `React 19` `Zustand` `Vite` `Docker` `Nginx` `Bootstrap 5`

#### [Campus Virtual API](https://github.com/regueira2010/campus-virtual-api)
> **Servicio backend para administración de cursos y estudiantes**
* **La idea:** Proyecto central desarrollado durante las 24 sesiones del programa intensivo **Globant Talento Ready**.
* **Qué exploré aquí:** Desarrollo guiado por pruebas (TDD con JUnit), modelado de entidades de negocio y persistencia relacional limpia con Spring Data JPA.
* **Stack:** `Java` `Spring Boot` `JUnit 5` `Maven` `PostgreSQL`
